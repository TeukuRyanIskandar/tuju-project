# Decide: FA fact engine + news on the same screen

Type: grilling
Status: resolved
Blocked by: 01

## Question

Pitch Feedback FA: from data API (not PDF) + related news. Defaults: P/E,
dividend yield, ROE, revenue & profit growth (QoQ/YoY), debt/equity, operating
cash flow. Naim validates later.

Pin metric definitions, null handling, and how news appears on the one screen.

## Answer

**FA metrics from yfinance-backed snapshots; nulls first-class; news =
headline+link list on the same stock screen.**

### FA metrics (PoC card)

| Metric | Source preference | Notes |
| --- | --- | --- |
| Trailing P/E | yfinance info / derived | Null if non-positive EPS |
| Dividend yield | info or TTM dividends / price | Null if none |
| ROE | info or derived | |
| Revenue growth QoQ | quarterly income stmt | Null if <2 quarters |
| Revenue growth YoY | same quarter prior year | Null if missing |
| Profit (net income) growth QoQ / YoY | same | |
| Debt / equity | info or balance sheet | Often empty for banks — show N/A |
| Operating cash flow | cash-flow statement latest | Null if missing |

- Persist into / read from domain snapshots where possible (extend free-tier
  `FundamentalsSnapshot` in BE spec, or a PoC-specific fact builder in the worker
  that reads NestJS APIs). **Single formula module** — do not recompute differently
  in LLM prompts.
- Period anchor: **`quarterly`** for growth; valuation ratios use TTM / trailing
  as vendor provides.

### Null / sparse handling

- Missing metric → omit from “fired” highlights; still list as N/A in the metrics
  table so the card does not look fabricated.
- Banks / financials: expect D/E gaps; narrative must not invent leverage.

### News (same screen, not inside the FA job artifact)

- **Primary:** existing free-tier news read model (RSS headline+link, ticker-tagged)
  scoped to the company — already on `GET` news routes.
- **Supplement (optional):** yfinance `.news` if research confirms useful MY
  coverage; otherwise skip (Pitch Feedback homework remains open — **non-blocking**:
  empty news list is an allowed PoC state with honest empty UI).
- News is **not** generated by the FA LLM job; it is a separate read block on the
  screen (ticket 07).

### Deferred

- PDF / annual-report extraction for FA.
- Peer-relative valuation.
